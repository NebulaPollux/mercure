# Fluxo de trabalho

- Para qualquer tarefa que envolva mais de uma edição de arquivo ou 
  mais de um passo lógico, use a ferramenta todowrite ANTES de começar 
  a editar, quebrando a tarefa em passos pequenos e sequenciais.
- Execute um passo de cada vez. Marque cada item como concluído antes 
  de seguir para o próximo.
- Nunca pergunte informações que você já pode descobrir sozinho usando 
  grep, glob ou read. Só pergunte ao usuário quando a informação 
  genuinamente não existir no projeto.
- Para tarefas simples de um passo só, pode executar direto sem usar 
  todowrite.
